# 🖼️ AI Image Tagger - Automatic Caption & Hashtag Generator


[![Streamlit](https://img.shields.io/badge/Streamlit-FF4B4B?style=for-the-badge&logo=Streamlit&logoColor=white)](https://streamlit.io/)
[![Python](https://img.shields.io/badge/Python-3.10+-3776AB?style=for-the-badge&logo=python&logoColor=white)](https://python.org/)
[![Gemini](https://img.shields.io/badge/Google_Gemini-4285F4?style=for-the-badge&logo=google&logoColor=white)](https://cloud.google.com/gemini)
[![License](https://img.shields.io/badge/License-MIT-green?style=for-the-badge)](LICENSE)

An intelligent application that automatically generates descriptive captions and relevant hashtags for your images using Google's Gemini AI.

## ✨ Key Features

| Feature | Description |
|---------|-------------|
| **📤 Image Upload** | Supports JPG, PNG, JPEG formats with preview |
| **💬 Smart Captioning** | Generates human-like descriptions for images |
| **🏷️ Hashtag Extraction** | Produces relevant tags for social media |
| **🔒 API Key Validation** | Secure handling of Google Gemini credentials |
| **🎨 Visual Results** | Displays image with generated content side-by-side |

## 🛠️ Installation & Usage

1. **Clone the repository**:
   ```bash
   git clone https://github.com/dheeraj7000/AI-image-tagger.git
   cd AI-image-tagger
   ```

2. **Install dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

3. **Run the application**:
   ```bash
   streamlit run app.py
   ```

4. **Enter your [Google AI Studio API key](https://makersuite.google.com/app/apikey)** when prompted

5. **Upload an image** and get instant captions + hashtags!
